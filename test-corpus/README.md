# Test corpus

Formula lists read by `CorpusTest` in `latex-parser/src/jvmTest`. Nothing here ships in a
published artifact.

One formula per line. Blank lines and lines whose first non-whitespace character is `#` are
comments.

## `baselines/`

Generated by `CorpusTest`, one formula per line:

- `unsupported.txt`: formulas that parse with an error diagnostic, an `Error` node or an
  unrecognized command.
- `incremental-mismatch.txt`: formulas that, appended to `IncrementalLatexParser` one character
  at a time, end in a different tree than `LatexParser.parse`.

A test fails when its baseline is out of date in either direction: a formula newly listed, or a
listed formula that no longer belongs. If the change is intended, regenerate both with:

```bash
UPDATE_CORPUS_BASELINE=1 ./gradlew :latex-parser:jvmTest --tests "*CorpusTest*"
```
